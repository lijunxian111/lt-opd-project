01 / THE IDEA

Teach the model
where it actually goes.

Extreme compression changes both what a model sees and the responses it produces.

LT-OPD trains a low-token student on its own generated prefixes, supervised by a frozen full-token copy. A decreasing token-budget curriculum supports adaptation. At inference, the compressed student runs alone.

Read the full abstract and paper ↗
02 / METHOD

Same model. Different visual budgets.

Low-Token On-Policy Distillation

01

Generate

The compressed student produces a response using reduced visual inputs.

02

Self-teach

A frozen teacher supplies next-token distributions on those same prefixes.

03

Adapt

Token-level Jensen–Shannon divergence aligns the student with its teacher.
